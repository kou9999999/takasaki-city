# 高崎市版移行計画

## 1. 概要

福岡市版（`fukuoka-city/develop`）をベースに、高崎市議会向けの「みらい議会ー高崎市版」を作成する。
手順は [別地域向けfork手順](../kawasaki/20260304_1000_別地域向けfork手順.md) および [福岡市版移行設計書](../fukuoka/20260321_1000_福岡市版移行設計書.md) に準拠する。

### ブランチ戦略

```
kawasaki/develop       ← チームみらい上流（取り込み専用）
fukuoka-city/develop   ← 福岡市版（取り込み専用・高崎市版のベース）
takasaki-city/develop  ← 高崎市版の統合ブランチ（PRの送り先）
    └── takasaki-city/feat/xxx 等の作業ブランチ → takasaki-city/develop へPR
```
